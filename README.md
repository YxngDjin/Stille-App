# 🌿 Stille

**Dein stiller Begleiter für schwierige Tage.**

Stille ist ein kostenloses, werbefreies Stimmungstagebuch für iOS. Kein Druck, kein Urteil — nur du.

---

## Features

- **Täglicher Check-in** — Wie geht es dir heute? Wähle eine Stimmung, schreib optional eine Notiz.
- **Stimmungsverlauf** — Sieh deine Stimmung über die letzten 30 Tage auf einen Blick.
- **Lichtblicke** — Sammle kleine positive Momente für schwere Tage.
- **Geführte Übungen** — 4-7-8 Atemübung, 5-4-3-2-1 Grounding, Meditation & Achtsames Gehen.
- **Hilfe griffbereit** — Telefonseelsorge immer einen Tap entfernt.
- **Privatsphäre** — Alle Daten bleiben auf deinem Gerät. Keine Cloud, keine Accounts.

## Häufige Fragen

**Sind meine Daten sicher?**  
Ja — alle Daten werden ausschließlich lokal auf deinem iPhone gespeichert. Wir haben keinen Zugriff darauf.

**Kann ich meine Daten exportieren?**  
Ja — in den Einstellungen kannst du alle Einträge und Lichtblicke als JSON-Datei exportieren.

**Die App stürzt ab / funktioniert nicht richtig.**  
Erstelle bitte ein [Issue](https://github.com/dennislehmann/stille-app/issues/new) mit einer kurzen Beschreibung des Problems und deiner iOS-Version.

**Wie kann ich Stille unterstützen?**  
Ein kleines Trinkgeld über die In-App Käufe hilft mir, die App weiterzuentwickeln. Danke! ☕
